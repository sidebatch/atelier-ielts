## 이 앱은 뭐가 다른가요

IELTS Writing Task 2 공부의 가장 큰 장벽은 "매번 40분씩 직접 써야 한다"는 부담입니다.
Writing Atelier는 **수동적 학습자**를 위해 설계됐어요. 쓰는 연습은 없고, 대신:

- 📖 **모범 에세이 읽기** — Band 9 수준 에세이 5개 (의견형 / 논의형 / 장단점형 / 문제-해결형 / 이중질문형)
- 🎨 **색깔 주석 탭하기** — 바꿔쓰기 · 중심문장 · 연결어 · 고급어휘 · 복문구조가 색으로 표시되고, 탭하면 "왜 좋은지" 한국어 해설 + 바로 써먹는 문장 패턴 제공
- ✅ **이해 퀴즈** — 에세이마다 2문항, 읽은 게 남는지 확인
- 🎯 **약점 드릴 32문항** — 4개 평가기준(TR/CC/LR/GRA)별 8문항 객관식. 가장 약한 기준을 자동으로 찾아 추천
- 🗓 **학습 예약** — 시간을 정해두면 앱이 알려줘요 (앱이 열려 있을 때)
- 📊 **학습 기록** — 연속일, 읽은 에세이, 드릴 최고 기록

공식 IELTS Writing Task 2 밴드 디스크립터의 4개 평가기준에 맞춰 설계됐습니다.
(Task Response · Coherence & Cohesion · Lexical Resource · Grammatical Range & Accuracy, 각 25%)

## 오늘의 15분 루틴

1. 모범 에세이 1개 읽기 (10분) — 색깔 표시를 탭하면서
2. 약점 드릴 1세트 풀기 (5분)

홈 화면이 "다음에 읽을 에세이"와 "지금 가장 약한 드릴"을 알아서 골라줍니다.

## 기술

- 단일 `index.html` 파일 (CSS + JS 내장, 프레임워크 없음)
- GitHub Pages로 배포, PWA (오프라인 캐시 + 홈 화면 설치)
- 학습 기록은 브라우저 `localStorage`에만 저장 — 서버 전송 없음
